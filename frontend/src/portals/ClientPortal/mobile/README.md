# Royal Square Financial - React Native Mobile App

Cross-platform React Native mobile application for Royal Square Financial wealth management, advisor client overview, goal tracking, and accident/loss claims.

n## Live Preview
- **Web App**: [https://royalsync-mobile.pages.dev/](https://royalsync-mobile.pages.dev/)

## Key Features
- **Luxury Brand Aesthetic**: Crimson (`#c0181a`), Gold (`#c9a84c`), and sleek dark UI tokens.
- **Splash & Dynamic Onboarding**: Animated entrance and interactive carousel.
- **Advisor Authentication**: Login & multi-step account registration.
- **Home Dashboard**: Total AUM (R 12.83M), MTD metrics, mini performance sparkline, quick actions, and compliance alerts.
- **Client Portfolio**: Real-time client list, search, 12-month performance breakdown, and product coverage tags.
- **Wealth Goal Tracker**: Aggregated progress ring and individualized target trackers.
- **Step-by-Step Accident & Loss Claims Wizard**:
  - Step 1: At the Scene checklist with instant checkbox toggles.
  - Step 2: Insurer selector (Santam, Discovery, Sanlam, Old Mutual, etc.) & incident inputs.
  - Step 3: Document uploads (police report, photos, ID, licence).
  - Step 4: Submission confirmation with generated claim identifier.
- **Advisor Profile**: FSP 49291 credentials, fee structure, office contact, and Notice of Appointment validation.

## Getting Started

### 1. Install Dependencies
```bash
cd mobile
npm install
```

### 2. Start Expo Development Server
```bash
npm start
```

### 3. Run on Target Platforms
- **iOS Simulator**: Press `i` in the terminal
- **Android Emulator / Device**: Press `a` in the terminal
- **Web Preview**: Press `w` in the terminal or run `npm run web`
- **Physical Device**: Scan the QR code with the Expo Go app
